# แดชบอร์ดยอดขาย บ้านสบาย ช็อป

ซอร์สโค้ดของแดชบอร์ดบน claude.ai (Dashboard Artifact) สำหรับผู้จัดการร้าน
ผู้ใช้อัปโหลด `orders.csv` (และ `products.csv` สำหรับกำไรขั้นต้น) แล้วระบบคำนวณทั้งหมดในเบราว์เซอร์ **ไม่มีข้อมูลฝังในโค้ด**

แดชบอร์ดที่เผยแพร่: https://claude.ai/artifact/ETi8L1JVZCdBPfVBr1qjtF

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | สไตล์ (ฟอนต์ Prompt, สีการ์ด KPI, เลย์เอาต์) และโหลดสคริปต์ตามลำดับ |
| `app.js` | แอป React (เขียนด้วย `React.createElement` ไม่ใช้ JSX) อ่าน CSV, คำนวณ, วาดกราฟ, สรุปผู้บริหาร, ส่งออก PDF |
| `react.js`, `react-dom.js` | React 18.3.1 (UMD production, MIT) จาก npm |

ใน `index.html` ฟอนต์อ้างถึงเป็น `/_blob/<id>` ซึ่งเป็นไฟล์ชุดเดียวกับใน `fonts/` ที่อัปโหลดไว้กับ artifact
หน้าเว็บนี้รันภายในแดชบอร์ดของ claude.ai เท่านั้น (ใช้ `dash.colors`, `dash.setLink`, `d3` และ `claude.use("sample")` ที่แดชบอร์ดเตรียมให้)

## นิยาม (ตาม `CLAUDE.md`)

- **ยอดขายสุทธิ** = `qty × unit_price × (1 − discount_pct/100)` เฉพาะ `status == "จัดส่งสำเร็จ"` ไม่รวม `shipping_fee`
- **กำไรขั้นต้น** = ยอดขายสุทธิ − `qty × unit_cost` (จาก `products.csv` เชื่อมด้วย `product_id`)
- **AOV** = ยอดขายสุทธิ ÷ คำสั่งซื้อที่จัดส่งสำเร็จ
- **อัตรายกเลิก / อัตราคืน** = แถวสถานะนั้น ÷ คำสั่งซื้อทั้งหมดในตัวกรอง × 100
- **วันเมกะเซล** = วันที่เลขวันเท่ากับเลขเดือน (10.10, 11.11, 12.12, 3.3, 6.6, 9.9)

## แท็บ

- **ภาพรวม** — การ์ด KPI 5 ใบ, แถบตรวจสอบจำนวนแถว/สถานะ, ยอดรายเดือน, ตามช่องทาง, ตามหมวด, ตามบริษัทขนส่ง (แยกหมวดเป็น %), ตามภูมิภาคและจังหวัด
- **วันเมกะเซล** — สัดส่วนยอดขายและ % กำไรขั้นต้นเทียบวันปกติ, กราฟรายวัน, ตารางรายละเอียด
- **บทสรุปผู้บริหาร** — ส่ง JSON ตัวเลขสรุป (≤ 30 ค่า ไม่ส่งข้อมูลดิบ) ให้ Claude เขียน 5 บรรทัด
  และส่งออก PDF (หัวข้อย่อยแบบ bullet ≤ 100 คำ/หัวข้อ, ข้อเสนอแนะแบบเหตุ → ผล → แนวทางแก้ไข, ตารางตัวเลขสรุป)
  หน้าตรวจว่าไม่มีตัวเลขนอก JSON และครอบคลุมทุกค่า; PDF เป็นภาพหน้ากระดาษพร้อมชั้นข้อความที่มองไม่เห็นจึงเลือก/คัดลอกได้

ตัวกรองภูมิภาคและหมวดสินค้ามีผลกับทุกการ์ด กราฟ และบทสรุป
